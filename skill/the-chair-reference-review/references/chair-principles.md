# The Chair 的推荐信判断原则

本文件提炼自 The 椅子的小红书帖子《换个视角看推荐信：招生官到底想读什么？》，是本 Skill 的思想底座，而不是一套机械评分表。

## 1. 招生官真正想确认的三件事

### 推荐人有没有资格评价

推荐人的职位不是结论。真正重要的是：

- 推荐人是谁、以什么身份接触申请者；
- 双方认识多久；
- 在什么课程、研究、项目或工作场景中相处；
- 推荐人实际观察过申请者的哪些工作；
- 是否存在合理的比较范围。

名气很大但接触很浅的推荐人，未必比持续指导申请者的老师或主管更有说服力。

### 评价是否可信

可信的推荐信不是形容词更高级，而是评价背后有可观察的事实。

用一个最直接的测试：

> 删掉所有形容词后，还能不能看出申请者是谁？

如果能，说明信里有场景、行动、结果和差异化证据；如果不能，说明内容主要由套话和空洞夸奖构成。

每个重要评价都应尽量回答：

> 在什么情况下，申请者做了什么，产生了什么结果，因此推荐人形成了什么判断？

“课后主动 follow up 反馈并继续推进 research”通常比“非常努力”更有说服力。

### 申请者和项目是否匹配

推荐信不是孤立材料。它与 CV、PS 和其他推荐信共同拼出申请者的形象。推荐人应为自己真正观察过、且与目标项目有关的能力背书。

项目契合不等于照抄项目官网或罗列课程，而是：

> 推荐人观察到的能力或成长轨迹，为什么足以支持申请者进入这个项目继续训练？

想突出代码与实证能力，应优先选择真正见过申请者进行相关工作的老师；想突出法律实务判断，则应选择能观察其分析、写作或案件工作的推荐人。

## 2. 四个部分是证据顺序

推荐信常见的四个功能是：

1. **开头交代关系**：推荐人是谁、如何认识申请者、为何有资格评价。
2. **主体证据故事**：选一段最能支撑核心能力的经历，用具体场景、行动和结果展开。
3. **品质与第二维度**：通过另一段场景或持续行为展示主动性、严谨性、独立性、合作等品质。
4. **结尾下结论**：把前文证据收束到项目适配，并给出与证据相称的推荐强度。

这不是要求每封信必须四段，而是要求完整完成四个证据功能。

## 3. 用故事替代形容词

主体段的重点不是堆叠十个褒义词，而是把一个故事讲清楚。可以借用以下证据链：

> 情境或难点 -> 申请者的具体行动 -> 结果或认可 -> 推荐人的判断

一段扎实证据通常比多个泛泛经历更有用。选材应服务于整套申请材料的分工，不必重复 CV 和 PS 已经说过的全部内容。

## 4. 细节必须符合推荐人的视角

真实不等于数字越多越好。教授对共同经历的记忆不一定比申请者更精确；若信中出现推荐人不太可能记住的作业小数分、私人动机或过度完整的内心转折，反而会削弱可信度。

判断细节时要问：

- 推荐人当时是否在场或能接触相关记录？
- 这个数字是否来自其职责范围内的正式记录？
- 这段反思是推荐人的观察，还是申请者自己的 PS 语言？
- 叙述是否过度贴合申请者口吻？

细节真实、数字克制，比虚假的精确更稳。

## 5. 推荐强度要与证据相称

`my highest recommendation without reservation` 一类最高强度表达，只有在关系深度、比较基础和证据都足够时才可信。推荐人不需要对每位学生、每个项目都使用最高档表达。

结尾要完成两件事：

1. 说明前文证据为何支持申请者适配目标项目；
2. 给出符合真实判断的推荐强度。

强度不是越高越好；可信且被证据挣来的强度才有效。

## 6. 跨材料判断

- CV 负责提供可快速核验的经历与成果结构。
- PS 负责解释申请者的动机、问题意识、发展轨迹与项目需求。
- 推荐信负责提供第三方观察、比较和背书。

三者可以指向同一能力，但不能只是重复同一句话。推荐信应提供申请者自己无法独立证明的外部视角。

## 7. 评价时坚持

- 观察基础优先于推荐人光环。
- 具体证据优先于高级形容词。
- 可信视角优先于虚假精确。
- 材料互补优先于重复罗列。
- 项目相关优先于官网关键词。
- 校准后的真实推荐优先于无依据的最高赞誉。
- 先做判断，再与用户校准，最后给修改建议。
