# 推荐信诊断输入模板

请使用者尽量复制并填写以下模板。缺失信息可以标注“暂无”或“未知”，但不要自行补写。

```text
请使用 $the-chair-reference-review 对这封推荐信做定性诊断。第一轮请先判断，不给总分，也不直接重写整封信；等我确认判断后，再给修改建议。

【申请类别】本科 / 授课型硕士 / 研究型硕士 / PhD / 奖学金 / 其他：
【目标学校】
【目标项目（完整名称）】
【项目官网或官方项目介绍】
【官方推荐信题目或要求】如无明确要求请写“无”：
【字数、字符或格式限制】
【提交方式或特殊要求】系统问卷 / 上传 PDF / 推荐人邮箱提交 / 其他：

【推荐人身份】姓名可匿名；请写职位、机构、学科或部门：
【与申请者的关系】课程教师 / 论文导师 / 项目导师 / 实习主管 / 雇主 / 其他：
【认识时间与接触频率】
【共同场景】课程、研究、项目、工作或其他：
【推荐人实际观察过的工作】
【合理的比较范围】如班级规模、指导学生范围；未知可不填：

【这封信希望重点证明的能力或形象】
【CV 与 PS】上传文件或简要说明相关经历（建议）：
【其他推荐信】如有，请说明推荐人及各自希望证明的能力（可选）：
【已确认可写入的事实】场景、行动、结果、反馈、排名或数字：
【尚未确认的事实】

【推荐信正文】上传 DOCX / PDF，或粘贴全文：
【希望重点检查】推荐资格 / 证据可信度 / 项目契合 / 多封信分工 / 语言真实性 / 格式与提交风险 / 其他：
```

## 输入规则

- 完整诊断至少需要推荐信正文、目标项目、推荐人关系与观察场景。
- 判断项目契合需要官方项目信息或用户粘贴的项目要求。
- 判断材料组合需要 CV、PS 摘要或其他推荐信的分工信息。
- 缺少项目时，可以诊断推荐资格和证据可信度，但项目契合必须标记 `not assessable`。
- 缺少推荐人关系或观察场景时，不得假设其评价资格；将相关判断标记 `not assessable`，并提出最少量的事实问题。
- 若用户只想快速预检，可以直接开始，但必须明确诊断边界。
